# 06. Object-Oriented Programming (OOP)

Master object-oriented concepts in Python, covering class construction, state management, and OOP paradigms.

## Included Files

* `01_classes_and_objects.py` — Creating classes, instantiating objects, instance variables vs class variables, and the `__init__` constructor.
* `02_inheritance.py` — Class inheritance, method overriding, single vs multiple inheritance, and invoking parent methods with `super()`.
* `03_encapsulation.py` — Access control naming conventions (Public, Protected `_`, Private `__`), getters/setters, and the `@property` decorator.
* `04_polymorphism.py` — Method overloading behavior and dunder/magic methods (`__str__`, `__repr__`, `__len__`, `__eq__`).

## The 4 Pillars of OOP

1. **Encapsulation** — Bundling data and methods together while restricting direct external access to internal states.
2. **Abstraction** — Hiding complex implementation details behind simple public interfaces.
3. **Inheritance** — Deriving new classes from existing ones to promote code reuse.
4. **Polymorphism** — Allowing different classes to respond to shared method calls in their own unique way.
